# 保守タスク管理

CSVをデータ元にしたローカル専用の保守タスク管理アプリです。Python標準ライブラリだけで動きます。

## 起動

```bash
python3 app.py
```

ブラウザで開きます。

```text
http://127.0.0.1:8000
```

## 考え方

データを2階層に整理しています。

- `work_items.csv`: 親タスク。保守、会議、調査、自社作業、その他。
- `tasks.csv`: 子タスク。親タスクの中で実際に進める作業。

保守は `CRM-0001` のようなIDで管理します。会議は `GI`、`食農`、`全体` などの種類を持てます。

## 画面

- カレンダー: 親タスクを1本の横棒で表示。未完了の子タスクだけ補助線として表示。
- 親タスク: 保守、会議、調査、自社作業を作成・編集・削除。
- 子タスク: 親タスク配下の小タスクを作成・編集・削除。

カレンダー左側のフォームからも親タスクを直接作成できます。標準の子タスクを作るチェックを入れると、保守なら見積もり、設計、開発、テスト、リリース準備などが自動作成されます。

## CSV

### `data/work_items.csv`

| 列 | 内容 |
| --- | --- |
| id | `CRM-0001` や `W001` |
| title | 親タスク名 |
| category | `保守`, `会議`, `調査`, `自社作業`, `その他` |
| kind | 会議なら `GI`, `食農`, `全体` など |
| status | 親タスクの状態 |
| meeting_setup_status | 会議設定の状態。`未設定`, `設定済み` |
| start_at | 開始日時 `YYYY-MM-DDTHH:MM` |
| end_at | 終了日時 `YYYY-MM-DDTHH:MM` |
| owner | 担当 |
| memo | メモ |

### `data/tasks.csv`

| 列 | 内容 |
| --- | --- |
| id | `T0001` のようなID |
| parent_id | 親タスクID |
| title | 子タスク名 |
| kind | 見積もり、設計、開発、資料など |
| status | `未実施`, `進行中`, `レビュー中`, `完了`, `保留` |
| start_at | 開始日時 |
| end_at | 終了日時 |
| owner | 担当 |
| sort_order | 並び順 |
| memo | メモ |
